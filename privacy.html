Privacy

Updated 6 November 2026

Your clipboard data

Insert stores your clips only on your Mac. Insert has no account and no cloud sync. Insert does not send your clips anywhere.

Network use

Insert connects to the internet only to check for updates. To do this, it downloads https://insert-app.vercel.app/appcast.xml. Like all web requests, this request includes your IP address and the version of Insert.

Insert checks your license key on your Mac. It does not send the key to a server.

Purchases

Stripe processes each purchase through Link. Stripe receives your payment details, and this website does not. To make your license key, this website gets your email address and the order number from Stripe. The license key contains these two values. This website does not store them in a database. The request logs of the host, Vercel, can keep the order number for a short time.

This website

This website has no analytics and no cookies. Vercel hosts the website and keeps standard server logs. The download links go to GitHub.
